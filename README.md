# HiddenProbe

Official implementation for
<pre>
<b>HiddenProbe</b>
&lt;authors&gt;
&lt;arXiv link&gt;
</pre>

HiddenProbe learns a small set of probe inputs, queries a frozen network with them and reads the network's
**hidden** responses to those probes (the ProbeGen baseline of [Kahana et al.](https://github.com/jonkahana/ProbeGen)
uses the same learned probes but reads only the network's outputs). This repository contains the three
weight-space tasks of the paper:

- **CIFAR-10 INR classification**: classify the image encoded by a SIREN from the SIREN's weights (augmented and
  non-augmented CIFAR-10 INR zoos).
- **CNN accuracy regression**: predict a CNN's test accuracy from its weights (CIFAR10-GS, CIFAR10 Wild Park, SVHN,
  MNIST-GS, Fashion-MNIST-GS).
- **Transformer accuracy regression**: predict a transformer's test accuracy from its weights (MNIST-Transformers,
  AGNews-Transformers).

## Setup environment

To run the experiments, first create a clean virtual environment and install the requirements.

```bash
conda create -n hiddenprobe python=3.11
conda activate hiddenprobe
pip install numpy pandas scipy tqdm einops safetensors transformers omegaconf
pip install torch --index-url https://download.pytorch.org/whl/cu118   # pick the build matching your CUDA
```

The PyTorch build must match your GPU/CUDA (see https://pytorch.org/get-started/locally/); a mismatched build
fails at the first CUDA call with "no kernel image available for execution on the device". `omegaconf` is used
only once, to unpickle the CNN Wild Park checkpoints while building its cache. All scripts use the active
environment's `python` and are run from the repository root.

Install the repo:

```bash
git clone -b hiddenprobe https://github.com/yonatansverdlov/HiddenProbe.git
cd HiddenProbe
```

## Datasets

Every dataset has a restart-safe setup script under `scripts/setup_data/` that downloads the public release
and installs it under `data/` (override the base with `DATA_ROOT=/path`). All datasets at once:
`bash scripts/setup_data/setup_all_datasets.sh`; see `scripts/setup_data/README.md` for details.

### INR classification

For INR classification, we use the CIFAR-10 INR dataset of [Neural Functional Transformers (NFN)](https://arxiv.org/abs/2305.13546)
(`siren_cifar_wts`): one SIREN (2 -> 32 -> 32 -> 3) per CIFAR-10 image, plus 20 random-init re-fits of every
training image. The same release serves both benchmarks: **non-augmented** (one SIREN per image in train, val
and test) and **augmented** (train additionally keeps every random-init re-fit of each training image). Labels
come from the checkpoint sub-directory name and the train / val / test split is by net index exactly as in the
[NFN code](https://github.com/AllanYangZhou/nfn); both split files are generated by
`scripts/setup_data/build_nfn_cifar_splits.py` next to the checkpoints.

#### CIFAR-10 INRs

```sh
bash scripts/setup_data/classification_cifar10.sh
```

### CNN generalization

For CNN accuracy regression we use the grayscale Small CNN Zoos of
[Unterthiner et al., 2020](https://github.com/google-research/google-research/tree/master/dnn_predict_accuracy)
(CIFAR10-GS, SVHN, MNIST-GS, Fashion-MNIST-GS) and the [_CNN Wild Park_](https://doi.org/10.5281/zenodo.12797219).
We provide the train / val / test splits inside this repository, under `scripts/setup_data/splits/`
(CIFAR10-GS and SVHN use the [NFN](https://github.com/AllanYangZhou/nfn) splits; CNN Wild Park uses the
[ProbeGen](https://github.com/jonkahana/ProbeGen) split; Fashion-MNIST-GS has no split file and the loader
generates its seed-0 split deterministically).

- [CIFAR10-GS](https://storage.googleapis.com/gresearch/smallcnnzoo-dataset/cifar10.tar.xz)
- [CNN Wild Park](https://zenodo.org/records/12797219)
- [SVHN](https://storage.googleapis.com/gresearch/smallcnnzoo-dataset/svhn_cropped.tar.xz)
- [MNIST-GS](https://storage.googleapis.com/gresearch/smallcnnzoo-dataset/mnist.tar.xz)
- [Fashion-MNIST-GS](https://storage.googleapis.com/gresearch/smallcnnzoo-dataset/fashion_mnist.tar.xz)

#### CIFAR10-GS

```sh
bash scripts/setup_data/regression_cifar10_gs.sh
```

### Transformer accuracy prediction

For transformer accuracy prediction, we use the MNIST-Transformers and AGNews-Transformers zoos of the
[Small Transformer Zoo](https://huggingface.co/datasets/anonymized-acamedia/Small-Transformer-Zoo)
(HuggingFace dataset `anonymized-acamedia/Small-Transformer-Zoo`). One example is a trained transformer
checkpoint (the epoch-75 checkpoint of every training run) and its released test accuracy, which is the
regression target. The train / val / test split is a seeded, run-disjoint 70/15/15 split over the runs, built
by the data loader. The setup scripts download the zoo and build the consolidated per-split cache
(`python main.py transformer cache --dataset {mnist,agnews} --data_root data`).

#### MNIST-Transformers

```sh
bash scripts/setup_data/regression_mnist_transformer.sh
```

#### AGNews-Transformers

```sh
bash scripts/setup_data/regression_agnews_transformer.sh
```

## Running the experiments

To run a specific experiment, you can use the provided scripts in the `scripts` directory. All of them call
the single entry point `main.py`, which dispatches to the task trainer in `models/`:

```
python main.py cnn_zoo     <trainer arguments>                       # CNN accuracy regression
python main.py transformer {train,count,cache,...} <arguments>       # transformer accuracy regression
python main.py inr --method {hiddenprobe,probegen} <trainer arguments>   # CIFAR-10 INR classification
```

Model selection always uses the validation split only; the test split is scored once, at the selected
checkpoint (best-validation checkpoint; the CIFAR10 Wild Park scripts additionally report the final epoch).
Every regression script takes the number of probes (CNN zoos) or the seed (transformer zoos) as an optional
first argument; the classification scripts take `[Q] [SEED]`. The `qsweep_*` scripts run every probe count in
turn, each with its own winning configuration, and `DRYRUN=1` prints their commands instead of running them.

### HiddenProbe

CIFAR-10 INR classification (`scripts/HiddenProbe/classification`):

- CIFAR-10 INR classification (non-augmented): `bash scripts/HiddenProbe/classification/run_cifar10_inr_nonaug.sh`
- CIFAR-10 INR classification (augmented): `bash scripts/HiddenProbe/classification/run_cifar10_inr_aug.sh`
- CIFAR-10 INR classification (non-augmented) over all probe counts: `bash scripts/HiddenProbe/classification/qsweep_cifar10_inr_nonaug.sh`
- CIFAR-10 INR classification (augmented) over all probe counts: `bash scripts/HiddenProbe/classification/qsweep_cifar10_inr_aug.sh`

CNN accuracy regression (`scripts/HiddenProbe/regression`):

- CIFAR10-GS Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_cifar10_gs_regression.sh 128`
- CIFAR10 Wild Park Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_cifar10_wp_regression.sh 128`
- SVHN Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_svhn_regression.sh 128`
- MNIST-GS Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_mnist_regression.sh 128`
- Fashion-MNIST-GS Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_fmnist_regression.sh 128`
- CIFAR10 Wild Park Accuracy Prediction over all probe counts: `bash scripts/HiddenProbe/regression/qsweep_cifar10_wp.sh`
- SVHN Accuracy Prediction over all probe counts: `bash scripts/HiddenProbe/regression/qsweep_svhn.sh`
- MNIST-GS Accuracy Prediction over all probe counts: `bash scripts/HiddenProbe/regression/qsweep_mnist.sh`
- Fashion-MNIST-GS Accuracy Prediction over all probe counts: `bash scripts/HiddenProbe/regression/qsweep_fmnist.sh`

Transformer accuracy regression (`scripts/HiddenProbe/regression`; each script trains with
`main.py transformer train` and then scores the best-validation checkpoint on the test split with
`python -m models.transformer.evaluate <run_dir>`):

- MNIST-Transformers Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_mnist_transformer.sh`
- AGNews-Transformers Accuracy Prediction: `bash scripts/HiddenProbe/regression/run_agnews_transformer.sh`
- MNIST-Transformers Accuracy Prediction over all probe counts: `bash scripts/HiddenProbe/regression/qsweep_mnist_transformer.sh`
- AGNews-Transformers Accuracy Prediction over all probe counts: `bash scripts/HiddenProbe/regression/qsweep_agnews_transformer.sh`

The transformer scripts also support the accuracy-threshold protocol: setting `CUT=<threshold>` (for example
`CUT=0.8 bash scripts/HiddenProbe/regression/run_mnist_transformer.sh`) retrains on the training / validation
runs whose accuracy is at least the threshold, and the evaluator then scores the test runs whose accuracy is
at least the threshold.
